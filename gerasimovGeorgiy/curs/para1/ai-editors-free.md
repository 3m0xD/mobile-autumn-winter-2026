## Сравнительная таблица

| Инструмент | Что это | Free по сути |
|---|---|---|
| **VS Code** | Редактор | Весь редактор бесплатно; ИИ — отдельно |
| **Copilot Free** | ИИ в VS Code | ~2000 дополнений + 50 chat/мес; у студентов — Student |
| **Cursor Hobby** | AI-редактор | Есть, но лимиты быстро кончаются |

## Коротко по пунктам

### VS Code
![VS Code](./images/vscode.png)

- База курса (Expo / React Native)
- ИИ ставится расширением

### GitHub Copilot Free
![Copilot](./images/copilot.png)

- ~2000 автодополнений/мес + 50 chat/мес
- **Copilot Student** (GitHub Education): автодополнения без месячного лимита, chat/agent ограничены
- Удобно при сдаче через GitHub fork/PR

### Cursor (Hobby)
![Cursor](./images/cursor.png)

- Отдельный редактор на базе VS Code
- Free без карты; Agent/Chat/Tab с лимитами (смотреть Dashboard)

### Windsurf Free
![Windsurf](./images/windsurf.png)

- Безлимитный Tab (autocomplete)
- Агент — по дневной/недельной квоте

### Continue.dev
![Continue](./images/continue.png)

- Open-source расширение для VS Code
- Свой API-ключ или локальная модель (Ollama)
- В 2026 связан с Cursor — hosted может меняться

### Gemini / Gemini Code Assist
![Gemini](./images/gemini.png)

- С **18.06.2026** consumer IDE/CLI tier отключён
- Старые «6000 запросов/день» не обещать
- Браузерный чат Gemini — только как «поговорить про ошибку»

## Рекомендация на курс

1. Поставь **VS Code**
2. ИИ: **Copilot Free** (или Student) **или** чат в браузере
3. Cursor / Windsurf — по желанию
4. На защите код должен понимать **ты**
