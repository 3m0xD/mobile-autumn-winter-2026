На паре разобрали рынок, ИИ-помощников и Spec-Driven Development.  
Дальше курс — практика в **React Native + Expo**, сдача через **GitHub**.

Если сейчас не настроить окружение, на следующей паре потеряешь время, пока остальные уже кодят.

## Обязательный минимум (сделать всем)

### 1. Аккаунты и доступ

- [ ] Аккаунт **GitHub**
- [ ] На телефон: **Expo Go** (App Store / Google Play)
- [ ] Выбран редактор: желательно **VS Code**
- [ ] (По желанию) ИИ: **Copilot Free / Student** или чат в браузере

### 2. Окружение на ноутбуке

- [ ] Установлен **Node.js** LTS
- [ ] В терминале работает: `node -v` и `npm -v`
- [ ] VS Code открывается, терминал внутри него ок

### 3. Репозиторий курса

Репо семестра: https://github.com/arri1/mobile-autumn-winter-2026

- [ ] Сделать **fork** репозитория
- [ ] Склонировать **свой** fork
- [ ] Создать папку `ФамилияИмя` (как в прошлом году, в lowerCamelCase/без пробелов — как скажет препод)
- [ ] Внутри папки — `README.md`:
  - ФИО
  - группа
  - контакты (Telegram / email)
  - одной фразой: зачем тебе мобильная разработка
- [ ] Открыть **Pull Request** в общий репо курса

> Если PR ещё «пустой» (только README) — нормально. Главное — процесс сдачи освоен.

### 4. Первый Expo-проект

Внутри своей папки:

```bash
npx create-expo-app@latest . --template blank-typescript
```

(или в подпапку `my-app`, если так удобнее — главное, чтобы путь был понятен в PR)

- [ ] Проект создаётся без ошибок
- [ ] `npx expo start` запускается
- [ ] На телефоне в Expo Go виден стартовый экран
- [ ] Изменения закоммичены и пушнуты в fork / PR обновлён

## ДЗ по теме пары (ИИ + голова)

### 5. Один ИИ-помощник — потрогать руками

- [ ] Задать ИИ **плохой** промпт: «напиши приложение со счётчиком»
- [ ] Задать **хороший** промпт со стеком (Expo + TypeScript + useState…)
- [ ] В `README.md` своей папки добавить блок:

```markdown
## ИИ на курсе
- Чем пользуюсь: …
- Чему научился на 1 паре: …
- Правило: код на защите объясняю я
```

### 6. Мини-спека (SDD) на следующую лабу

В файле `SPECS/lab-01.md` (или в README) набросать спеку будущего экрана **useState-счётчик**:

- [ ] Цель
- [ ] Стек и ограничения
- [ ] Acceptance criteria (чеклист «готово, если»)
- [ ] Что **не** делаем

Не обязательно писать код счётчика сейчас — достаточно спеки. Код будет на практике.

2. Папку с README

## Если что-то сломалось

| Проблема | Что сделать |
|---|---|
| Node не ставится | Бери LTS с nodejs.org; без «кривых» менеджеров наобум |
| Expo Go не видит проект | Один Wi‑Fi / tunnel mode в Expo; проверь файрвол |
| PR не куда открыть | Fork должен быть от `mobile-autumn-winter-2026`, не случайный репо |
| Страшно / не успел | Минимум: GitHub + README + PR; Expo добить к началу пары 2 |

Напиши преподу / в чат группы **до пары**, если застрял на установке — не в первые 40 минут занятия.
