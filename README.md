Репозиторий: [https://github.com/arri1/mobile-autumn-winter-2026](https://github.com/arri1/mobile-autumn-winter-2026)

## Как сдать работу (обязательно прочитай)

### 1. Сделай fork

Нажми **Fork** на странице репозитория.  
Дальше работаешь **в своём** fork, не в чужом.

### 2. Создай папку со своим именем

В корне репозитория (рядом с другими студентами) создай папку:

```text
фамилияИмя
```

Правила имени папки:

- только **латиница**
- **lowerCamelCase**
- сначала фамилия, потом имя

Примеры:

- `kokarevaSandara`
- `nikulinFedor`
- `gerasimovGeorgiy`

Неправильно: `KokarevaSandara`, `kokareva_sandara`, `Кокарева`, `my-app` в корне.

### 3. Положи README в свою папку

Файл: `фамилияИмя/README.md`

Внутри должно быть:

- ФИО
- группа

Пустой README или текст вроде `asdasd` **не принимается**.

### 4. Создай Expo-проект внутри своей папки

Пример:

```bash
cd фамилияИмя
npx create-expo-app@latest my-app --template blank-typescript
cd my-app
npx expo start
```

Нужны:

- Node.js (LTS)
- приложение **Expo Go** на телефоне



### 5. Открой Pull Request

Из своего fork в репозиторий курса:

`arri1/mobile-autumn-winter-2026` → ветка `main`

**Fork без PR преподаватель не видит.**  
Если сделал только fork — это ещё не сдача.

---



## Что должно быть в PR

Минимум на старт курса:

- [ ] папка `фамилияИмя`
- [ ] `README.md` по правилам выше
- [ ] Expo-проект внутри папки (хотя бы стартовый)
- [ ] открытый Pull Request

Не коммить:

- `node_modules/`

---



## Частые ошибки


| Ошибка                    | Что сделать                                    |
| ------------------------- | ---------------------------------------------- |
| Есть fork, нет PR         | Открой Pull Request в курсный репо             |
| Папка названа не так      | Переименуй в `фамилияИмя` (lowerCamelCase)     |
| README-пустышка           | Допиши ФИО, группу, контакт, мотивацию         |
| Проект лежит в корне репо | Перенеси внутрь своей папки                    |
| Не запускается Expo       | Проверь Node.js и Expo Go, напиши в чат группы |
